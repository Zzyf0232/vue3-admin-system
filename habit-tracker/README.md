# 每日打卡小程序

## 项目简介

一个基于微信小程序原生开发的每日习惯打卡应用，帮助用户养成和坚持好习惯。支持自定义习惯、图标和颜色、日历热力图、连续打卡统计、数据导入导出等功能。

## 技术栈

- 微信小程序原生框架（WXML + WXSS + JS）
- 本地数据存储（wx.getStorageSync / wx.setStorageSync）
- 纯原生开发，无任何第三方库和 UI 框架

## 核心实现

### 数据结构
```javascript
{
  habits: [
    { id: 'h...', name: '读书', color: '#2E7D5B', icon: 'book', createdAt: '2024-01-01' }
  ],
  records: {
    '2024-01-01': ['h...', 'h...'],  // 日期 -> 习惯ID数组
    '2024-01-02': ['h...']
  }
}
```

### 关键逻辑
- **连续全勤算法**：从今天往前回溯，跳过无习惯的天数，统计连续全勤天数
- **日历热力图**：根据当日完成率映射到 6 级颜色（0% → 100%）
- **数据迁移**：旧数据无 icon 字段时，按习惯名称自动匹配图标
- **数据导入导出**：JSON 序列化到剪贴板，导入时校验数据完整性
